# OpenSpamroll - Giveaway Plugin

**This project is unmaintained and looking for a new owner. Feel free to fork.**

Automated giveaway management plugin for FFXIV using /random rolls.

## Installation

This plugin is not yet in the main Dalamud repository. For now, build from source or check releases.

## Features

- Configurable winning number parameters
- Multi-winner support
- Anti-spam protection
- Multiple chat channel integration
- Automatic winner announcement
- Debug mode for testing

## Commands

- `/giveaway` - Open the main plugin window
- `/giveawaystart` - Start a new giveaway
- `/giveawaystop` - Stop the current giveaway
- `/giveawayconfig` - Open configuration

## Building

Standard Dalamud plugin build process:
```
dotnet build
```
